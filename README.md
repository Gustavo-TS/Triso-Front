# Triso Studio — React

Vitrine responsiva em React + Vite para uma loja de objetos impressos em 3D.

```bash
npm install
npm run dev
```

## Recursos

- Catálogo com busca, categorias e ordenação
- Anúncio detalhado de cada produto dentro da Triso
- Múltiplos links por produto para Mercado Livre, Shopee, Elo7 e outros marketplaces
- Painel administrativo em `?admin=1`
- Cadastro, edição, ativação e exclusão de produtos e seus canais de venda
- Rastreamento de cliques por produto, marketplace e URL
- Dashboard analítico com filtros de 7, 30 e 90 dias ou período personalizado
- Áreas separadas para desempenho e gestão de produtos
- Integração com a API Triso usando sessão por cookie HTTP-only
- Layout responsivo e acessível
- Formulário de newsletter demonstrativo
- Componentes e estado em React
